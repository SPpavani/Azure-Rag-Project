# 🚀 Azure RAG Project

This project demonstrates a **Retrieval-Augmented Generation (RAG)** pipeline using **Azure OpenAI** for embeddings + GPT, and **ChromaDB** for vector storage.

---

## 📂 Project Structure
RAG_Azure_Project/
│
├── main.py          # Builds embeddings DB
├── query.py         # Retrieves context + answers with GPT
├── requirements.txt # Dependencies
├── README.md        # Documentation
├── data/            # Place your documents here (txt, pdf, etc.)
└── db/              # Auto-created Chroma vector database
